Satellite position comes from live TLE fetch + real SGP4 propagation (or a verified cached snapshot / published-parameter fallback — see the badge on the orbit panel). Housekeeping telemetry is simulated, since no agency publishes that live for any real satellite, but the power channel is driven by the real eclipse state.
Detection — adaptive EWMA baseline with frozen-mean-during-anomaly and eclipse-detrending, running server-side, persisted to SQLite on every tick. Inspired by NASA JPL's Telemanom approach for the SMAP/MSL benchmark.
Diagnosis — computed stats are sent to Claude for a plain-English narrative; falls back to a local template if no API key is configured. The source is always labeled in the diagnosis panel.
